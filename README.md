PROTEGE

Plataforma de registo e proteção de equipamentos em Portugal.

Objetivo

Permitir que os utilizadores registem os seus equipamentos e tenham um local centralizado para guardar as respetivas informações.

Tecnologias

* React
* Vite
* JavaScript
* Vercel para alojamento

Estado atual

Versão inicial de demonstração. O registo de utilizadores, a base de dados e as funcionalidades de proteção ainda serão desenvolvidos.
